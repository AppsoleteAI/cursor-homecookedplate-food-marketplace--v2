# Filter search and Get GPS

Web, iOS, and Android use these same screens. The website publish includes them. An installed app keeps the previous screens until a new store build.

## Filter search

Signed out, Filter Search is not in the footer.

Signed in, a PlateMaker and a PlateTaker open the same Filter Search from Search. The control beside the search field is a funnel. It opens Filter Search.

The back chip on Filter Search returns to Search Meals for both roles. It does not follow the previous tab, which was Home. The reset control sits on the right of the header. It is the same 33-pixel glass circle as the other header chips, with a darker frost (`rgba(90, 48, 18, 0.34)`) and a white refresh mark. The notifications back chip uses that same frost.

These header chips use that same frost, for a PlateMaker and a PlateTaker. The white mark stays. The circle is darker than the pale glass it replaced.

| Chip | Header |
| --- | --- |
| Home bell | Home Kitchens, yellow |
| Incoming Orders back | Green. A PlateTaker does not open this screen |
| Food truck receipt | Orange |
| Farm basket | Green |
| Meal prep calendar | Blue |
| Catering order | Purple |
| Sit-down order | Gold |

Category, Cuisine, Dietary, and Tags slide sideways. The gap under each heading is short. Those rows still keep enough room for the chip shadow, and the ends of the row fade out, so the shadow is not cut into a hard line. Minimum rating wraps, so it never had that line.

## Manage Promotions, Area Offers, Charitable Gifts

Web, iOS, and Android use the same screens. This note is local until a web publish.

Signed in, a PlateMaker opens Manage Promotions, Area Offers, and Charitable Gifts from Create Meal. The back chip on each of those screens returns to Create Meal. Area Offers and Charitable Gifts opened from the kitchen dashboard return to the dashboard. Opened from a seller stand, they return to that stand.

Signed in, a PlateTaker can open Charitable Gifts and record a portion. Area Offers and Manage Promotions tell a PlateTaker that only a PlateMaker can set an offer. The back chip on all three screens returns to Create Meal for a PlateTaker as well. The Create Meal tab stays hidden for a PlateTaker. The screen still opens.

Signed out, those three screens send the person to sign in.

## Get GPS

Signed in, a PlateMaker sees Get GPS on the kitchen, on Profile, and on active orders. The green outline sits on the Get GPS words and the locate icon. The metro sentence sits outside that box. It says a new metro takes 30 minutes to update location. A PlateTaker does not see that card.

Signed in or signed out, both roles see Get GPS on Membership. That control is only the words and the locate icon, with the same green outline.
